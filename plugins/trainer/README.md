# Trainer (LID-TRN-08)

Part of the Locked In Dept. agent library. Builds a training plan and simple food targets for your level, days, kit and goal, so the Move and Fuel parts of the Locked In Ritual are done for you.

Install:

```
claude plugin marketplace add madebycompound/lockedindept
claude plugin install trainer@lockedin-dept
```

Then say "build my training plan" or run `/trainer:plan`. The plan is written to `~/.lockedindept/capacity/training-plan.md`.

Not medical advice. Check with a GP or physio before starting if you have an injury or a health condition.
